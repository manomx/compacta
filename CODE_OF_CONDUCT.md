# Code of conduct

Compacta welcomes people with different backgrounds, experience levels, and
languages. Be respectful, specific, and constructive. Critique code and ideas;
do not attack people.

Harassment, threats, discrimination, doxxing, sexualized attention, impersonation,
and publishing someone else's private information are not acceptable. Do not
post account credentials, private conversations, or identifying screenshots.

These expectations apply to issues, pull requests, discussions, reviews, and
other project spaces. Maintainers may edit or remove content, close discussions,
request changes in behavior, or restrict participation when necessary. Enforcement
should be proportionate to the behavior and its impact.

For abusive content, use GitHub's **Report content** controls. For another
participant's private information, report it without repeating it publicly.
Maintainer: [@manomx](https://github.com/manomx). GitHub's platform policies also apply.

This is Compacta's project-specific policy, not an adoption of an external code
of conduct with a separate enforcement organization.
